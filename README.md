# Python Cyberpunk Gigs

A collection of Python exercises for learning, practicing and deepening my Python programming skills.

The exercises are wrapped in a fictional **Cyberpunk universe**, where I take on different **Gigs** and solve them using Python.

The goal is to make learning Python more engaging while building a solid foundation for the **PCAP – Certified Associate in Python Programming** certification.

## The Idea

Instead of solving isolated programming exercises, every task is presented as a small job in a fictional cyberpunk world.

Each Gig focuses on different Python concepts and becomes more challenging as I progress.

## Ranks

The fictional ranking system represents my progress:

1. **Trainee**
2. **Bit Runner**
3. **Net Runner**
4. **Ghost Runner**
5. **Daemon Handler**
6. **ICE Breaker**
7. **Net Legend**

## Goals

* Improve my Python programming skills
* Understand Python fundamentals more deeply
* Practice writing clean and readable code
* Prepare for the PCAP certification
* Solve increasingly complex programming challenges
